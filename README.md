# 猜彩绘飞机 MVP

一个纯前端的彩绘民航飞机猜谜游戏。玩家通过最多 10 个只能回答“是 / 否”的问题，猜出准确的航空公司、机型和彩绘名称。

## 当前功能

- 本地静态彩绘飞机题库，开局随机抽题
- 中文自然语言问题输入与本地关键词解析
- 宽窄体 / 制造商二选一规则
- 地区问题最多 2 次，中国包含大陆、香港、澳门和台湾
- 颜色问题最多 2 次
- 飞机结构问题
- 3 次中途猜测与第 10 问后的最终确认
- 按提问次数计分
- 完整问答记录、答案揭晓和再来一局
- 桌面端与手机端响应式布局
- 图片加载失败保护

图片数据暂时使用航空主题占位区。后续可以把经过注册号和彩绘核验的图片信息填入题目记录的 `image` 字段，不影响现有游戏逻辑。

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

开发服务器启动后，根据终端显示的地址在浏览器访问，通常是 `http://localhost:5173`。

## 测试与构建

```bash
npm test
npm run build
```

## 问题示例

- 是宽体机吗？
- 是波音飞机吗？
- 是欧洲航空公司吗？
- 是中国航空公司吗？
- 机身有大面积蓝色吗？
- 有小翼吗？
- 是双发飞机吗？
- 有上层客舱吗？

无法识别、超出额度或违反方向规则的问题不会消耗正式问题次数。

## 数据维护

每条飞机记录都把玩法字段与资料来源放在一起。正式加入随机题库前，应人工核验：

1. 航空公司、注册号、具体机型和彩绘名称能够相互对应。
2. `largeAreaColors` 只记录大面积、有明显辨识度的颜色。
3. 结构字段与具体机型一致。
4. 图片确实对应目标注册号处于该彩绘状态，并记录作者、来源和许可证。

不要把密钥、账号密码或未经授权的图片提交到仓库。
